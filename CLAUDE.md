# Прежде чем что-либо менять

**Прочитай [docs/OPERATING_POLICY.md](docs/OPERATING_POLICY.md).**

Это не формальность. Половина правил там выведена из ошибок, которые уже
были допущены в этом проекте и которые иначе повторяются: месяц молча не
собиравшихся данных, статистика с раздутым знаменателем, `-703.2%` в отчёте,
push с красным тестом.

Изменения в политику вносятся **тем же коммитом**, что и в код. Политика,
разошедшаяся с кодом, хуже отсутствующей — ей верят, и она врёт.

## Перед пушем

    python3 scripts/preflight.py

Одна команда вместо дисциплины: тесты дважды подряд, чистота боевого
`state/`, контракт воркфлоу, импорт модулей, секреты, здоровье журнала.
Красный preflight — не пушить.

## Кратко, чтобы не начать не с того

- **Логика вердикта заморожена между чекпойнтами.** Показать то, что система
  уже посчитала, можно всегда. Изменить то, что она считает — только на
  чекпойнте. Ближайший: 23.08.2026.
- **TDD.** Тест пишется первым и должен упасть по делу.
- **Код возврата проверяется отдельно, не через пайп** (`pytest | tail && git
  commit` уже один раз пропустил красный тест — код брался у `tail`).
- **Прямой push в main**, CI на каждый push.
- Если сломалось шумно — сообщать немедленно, не дожидаясь чекпойнта.
